# 1. Distance Calculator

A simple Python program to calculate the distance between two points in a 2D Cartesian coordinate system.

## Steps to Calculate Distance

1. Enter the x-coordinate of the first point.
2. Enter the y-coordinate of the first point.
3. Enter the x-coordinate of the second point.
4. Enter the y-coordinate of the second point.
5. The program will display the distance between the two points.


# 2. Addition of Numbers

A simple Python program that adds two numbers provided by the user.

## Steps to Add Two Numbers

1. Enter the first number.
2. Enter the second number.
3. The program will display the sum of the two numbers.


# 3. Even or Odd Checker

A simple Python script to determine whether a given number is even or odd.

## Steps to Check Even or Odd

1. The program prompts the user to enter a number.
2. It checks if the number is divisible by 2.
3. If divisible, it prints "Even"; otherwise, it prints "Odd".

# 5. Square Calculator Program

A simple Python program that calculates and displays the square of each number in a predefined list.

## Steps to Calculate Squares
1. The program defines a list of numbers.
2. It uses a `for` loop to iterate over each number in the list.
3. For each number, it calculates the square and prints the result.


# 6. Countdown Program

A simple Python program to count down from a user-defined number to zero.

## Steps to Start the Countdown

1. Enter a non-negative integer to start the countdown.
2. The program will display each number in the countdown until it reaches zero.
3. A completion message will be displayed after the countdown finishes.
