# Distance Calculator

A simple Python program to calculate the distance between two points in a 2D Cartesian coordinate system.

## Steps to Calculate Distance

1. The program will prompt you to enter the x-coordinate of the first point.
2. Input the x-coordinate and press Enter.
3. The program will then prompt you to enter the y-coordinate of the first point.
4. Input the y-coordinate and press Enter.
5. Next, the program will prompt you to enter the x-coordinate of the second point.
6. Input the x-coordinate and press Enter.
7. The program will then prompt you to enter the y-coordinate of the second point.
8. Input the y-coordinate and press Enter.
9. The program will calculate the distance between the two points and display the result.


# Addition of Numbers

A simple Python program that adds two numbers provided by the user.

## Steps to Add Two Numbers

1. The program will prompt you to enter the first number.
2. Input the first number and press Enter.
3. The program will then prompt you to enter the second number.
4. Input the second number and press Enter.
5. The program will calculate the sum and display the result.

## How to Run

1. Download the Python script.
2. Open a terminal and navigate to the directory containing the script.
3. Run the program and follow the prompts to enter two numbers.
