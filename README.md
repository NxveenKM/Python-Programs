# Distance Calculator

A simple Python program to calculate the distance between two points in a 2D Cartesian coordinate system.

## Requirements

- Python 3.x

## How to Run

1. Download the Python script.
2. Open a terminal and navigate to the directory containing the script.
3. Execute the program and follow the prompts to enter the coordinates of the two points.

## Example Output

The program will display the calculated distance between the two points after you input the coordinates.
